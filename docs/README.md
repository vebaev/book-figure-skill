# Book Figure website

This directory contains the dependency-free public landing page for Book Figure.

The intended published address is [https://vebaev.github.io/book-figure-skill/](https://vebaev.github.io/book-figure-skill/).

To enable it, open the repository's **Settings → Pages**, select **Deploy from a branch**, then select the **main branch** and the **/docs directory**. Save the selection and GitHub Pages will publish `index.html` from this folder.
