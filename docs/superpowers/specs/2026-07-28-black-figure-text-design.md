# Pure-black figure text design

Date: 2026-07-28  
Status: approved

## Contract

- Every visible text glyph in a Book Figure output uses pure black `#000000`.
- The rule applies to Inter labels, headings, annotations, panel letters, polarity marks, and Bulgarian or English text.
- The rule also applies to Roboto Mono nucleotide sequences, sequence-only motifs, punctuation, hyphens, and 5′/3′ markers.
- Slate blue `#203B57` remains the primary color for object outlines, process arrows, connectors, cleavage marks, and other non-text linework.
- Letters or numbers printed inside colored biological objects are text and therefore remain `#000000`; unlabeled biological marks and molecular color encodings are not text.

## Scope

Update the skill prompt contract, authoritative design-token and semantic-color references, default agent prompt, README, contract fixtures, validator, and release notes. Existing raster examples are not regenerated by this release.
